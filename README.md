# Etyvo releases

Installers and update files for **Etyvo**, a background dictionary for Windows by AQuietDesk.

Download the latest `Etyvo_x.y.z_x64-setup.exe` from [Releases](https://github.com/AQuietDesk/etyvo-releases/releases/latest). Etyvo needs a licence key: get one at https://aquietdesk.com/etyvo.

Windows may say "Windows protected your PC" because AQuietDesk is a new publisher. Click **More info**, then **Run anyway**.
